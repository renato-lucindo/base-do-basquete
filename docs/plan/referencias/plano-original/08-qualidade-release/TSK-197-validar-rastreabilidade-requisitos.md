# Validar rastreabilidade dos requisitos

## Objetivo

Provar que cada item dos quatro documentos tem tarefa, evidência e decisão.

## Escopo permitido

Índice/matriz deste plano e resultados das tarefas.

## Passos

1. Enumerar todos os requisitos originais.
2. Vincular tarefa(s) e teste(s).
3. Marcar implementado, verificado, adiado ou rejeitado.
4. Exigir justificativa para itens adiados/rejeitados.
5. Confirmar que não houve função criada fora do escopo.

## Critérios de aceite

- Cobertura de 100% dos requisitos.
- Toda função crítica tem teste negativo e positivo.
- Nenhuma tarefa dependente avançou com gate reprovado.

## Não alterar

Código, banco ou ambientes.
