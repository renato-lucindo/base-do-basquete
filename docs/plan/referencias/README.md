# Material de referência — não executar

O diretório `plano-original/` preserva integralmente o pacote recebido para consulta de critérios detalhados e rastreabilidade.

- As tarefas `TSK-*` não compõem o backlog ativo.
- O registro de baseline bloqueada é somente histórico.
- Não criar branches, PRs ou gates individuais para essas tarefas.
- Usar os critérios antigos como checklist interno do pacote `WP-*` correspondente.
- Em caso de conflito, prevalecem os documentos ativos na raiz deste pacote.
