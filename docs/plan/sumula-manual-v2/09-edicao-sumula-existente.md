# Etapa 9 — Interface de edição de súmula existente

## Objetivo

Permitir revisar uma súmula já salva sem sobrescrever versões anteriores.

## Atividades

- Abrir a revisão ativa.
- Permitir as alterações previstas pelo plano funcional.
- Gerar diff legível antes da gravação.
- Mostrar impacto em placar e metadados.
- Exigir motivo e confirmação.
- Tratar conflito de versão sem sobrescrever dados.
- Permitir consulta às revisões anteriores.

## Checkpoint

Criar e revisar são fluxos completos independentes.
