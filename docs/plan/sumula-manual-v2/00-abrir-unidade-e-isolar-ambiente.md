# Etapa 0 — Abrir a unidade e isolar o ambiente

## Objetivo

Preparar uma unidade de trabalho isolada para a Súmula manual v2 sem misturar o estado atual do repositório.

## Atividades

- Criar worktree e branch exclusivos a partir da base estável definida.
- Registrar `WORK_UNIT`, objetivo, critérios de aceite, escopo negativo e revisores.
- Preservar integralmente o workspace atual.
- Definir a versão do editor e do `localStorage`.
- Assumir o `WRITE_LOCK` somente depois que a unidade atualmente ativa for liberada ou formalmente entregue.

## Checkpoint

Branch limpa, base registrada, `WRITE_LOCK` correto e `HANDOFF.md` com próximo passo exato.

## Commit esperado

Somente documentação operacional, se necessário.
