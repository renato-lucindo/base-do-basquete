## Decisões e limitações

- O plano atual do repositório privado não habilita o upload para GitHub Code Scanning. O CodeQL continua executando integralmente e preserva o SARIF como artefato; a integração nativa poderá ser ativada sem redesenho quando o recurso estiver disponível.
- A CSP permite scripts e estilos inline apenas enquanto o shell SSR do React Router exige bootstrap inline. O endurecimento por nonce fica associado à implementação de autenticação e sessões.
- Nenhum Worker de produção foi publicado e nenhum domínio próprio foi pesquisado ou configurado.
- Nenhuma credencial, chave Supabase ou secret é entregue ao frontend ou registrada no repositório.
